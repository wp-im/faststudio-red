# FastStudio Red

An independently implemented WordPress Classic theme for personal studios and portfolios. Red (`#d92525`) and warm paper (`#fff6ee`) are defaults; the entire semantic palette is configurable under **Appearance > Customize > FastStudio Red: Colors**.

## Editable content

- WordPress posts and featured images supply the selected-work grid and journal.
- Pages and post bodies remain native WordPress content (`the_content()`).
- Primary and footer navigation use native menu locations.
- Widgets: Homepage Additional introduction, Homepage Services, Homepage After selected work, Homepage Working Together and Contact, Posts and pages Sidebar, Footer Studio information. The two new homepage areas are optional and remain hidden until populated.
- The Customizer controls homepage copy, service/contact section headings, contact link, and all twelve color roles, including the soft-red section background.
- Site name and logo use WordPress Site Identity.

This is a standalone classic theme; it does not depend on another theme, external service, font download, tracking script, or bundled JavaScript. Text domain: `faststudio-red`. PHP 8.0+; WordPress 6.4+.
